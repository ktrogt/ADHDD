# ADHDD — HDD 楽器（役に立たない回路コンテスト）

ジャンクの 3.5 インチ HDD 4 台を、ヘッドを動かすコイル（VCM）に電流を流して鳴らし、音楽を演奏する楽器。学校の「役に立たない回路コンテスト」に出す。チームの通信規格 SmartNet（PC の MIDI → マスタの Pico → UART → 各楽器）につないで、ほかの楽器（ステッピングモーター、ソレノイドなど）と一緒に演奏する。

## 今の状態（2026-10-21）

- **設計の案まで**（`HDD楽器_仕様書.md` v0.7）。実機での確認、部品の購入、ファームウェアはまだ。基板（回路図・パターン）はユーザーが別のセッションで設計中。
- 4 チャンネルの本番は **JLCPCB に基板を発注**し（6 日ほどで届く）、部品は手はんだで付ける（付ける部品は約 41 点）。ユニバーサル基板での試作はせず、基板が届くまでにジャンパー線で HDD 1 台を鳴らして確かめる。
- 部品は**秋葉原の実店舗**（秋月電子通商・千石電商）でそろえる。
- 在庫・価格の情報は 2026-10-14〜19 時点。買いに行く前にもう一度確かめる。

## 構成のあらまし

| 項目 | 内容 |
|---|---|
| 音の出し方 | Pico で波形を計算し、62.5 kHz の PWM で H ブリッジを動かす（1 台 1 声）。予備として音の高さの矩形波も出せる |
| 回路 | Raspberry Pi Pico ＋ Pololu DRV8874 基板（#4035）× 4、12 V。発注する 2 層基板。温度センサーなどは足場だけ用意 |
| 取り付け | HDD を 1 台ずつ木の板に固定して響かせる。足りなければ圧電ピックアップ＋PA で拡声 |
| 安全 | 通信の途絶・プログラムの停止（Pico 内蔵のウォッチドッグ）から 0.5 秒以内に全停止。倒したままにできる停止スイッチ |
| 費用の目安 | 約 ¥3.5 万（HDD・基板の発注込み）。ピックアップと工具も買うと約 ¥4.4 万 |

## 次にやること

1. ユーザーの確認待ちの項目（下）を決める。
2. 基板を設計して JLCPCB に発注する（別のセッション。要件は仕様書 6.9）。
3. HDD と部品を秋葉原で買う（`部品表.md`）。Pololu 基板を改造し、1 枚ずつ確かめる（仕様書 8.1）。
4. 基板が届くまでに、ジャンパー線で HDD 1 台を鳴らして試験する（仕様書 8.1）: 音の出し方、発熱の目安、アームの片寄り、拡声が要るか。
5. 基板が届いたら組み立て、段階的に確かめ、本番の HDD 1 台ずつ温度の試験をする（仕様書 8.2）。
6. ファームウェアを書く（仕様書 7 章）。
7. 4 台そろえて 1 曲通す。当日は仕様書 8.4 のとおり。

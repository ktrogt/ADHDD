# ADHDD — HDD 楽器（役に立たない回路コンテスト）

ジャンクの 3.5 インチ HDD 4 台を、ヘッドを動かすコイル（VCM）に電流を流して鳴らし、音楽を演奏する楽器。学校の「役に立たない回路コンテスト」に出す。チームの通信規格 SmartNet（PC の MIDI → マスタの Pico → UART → 各楽器）につないで、ほかの楽器（ステッピングモーター、ソレノイドなど）と一緒に演奏する。

## 今の状態（2026-10-22）

- **設計の案まで**（`HDD楽器_仕様書.md` v0.7）。実機での確認、部品の購入、ファームウェアはまだ。
- **メイン基板はユニバーサル基板に手はんだで作ることになった**（2026-10-22、ユーザー）。Fusion で基板を作る試み（`基板/`）は、Fusion の MCP が回路図エディタへの書き込みを受け付けず、やめた。
- ユニバーサル基板の配置と配線を Codex に作らせて比べている途中（`ユニバーサル基板/README.md`）。基板は秋月 104708（155 × 114 mm）。つながりが正解と一致し、決まりごとも満たす案（L1・L4）まではできた。今は詰めてジャンパーを減らす仕上げ（L5）の途中で中断している。
- ユニバーサル基板に載せるための部品の差し替え（コイルのコネクタ → XH 3 ピン、DC ジャック → DIP 化キット、1N5822 → MBR3045FCT など）は決めたが、**`部品表.md` と仕様書にはまだ入れていない**。
- 部品は**秋葉原の実店舗**（秋月電子通商・千石電商）でそろえる。
- 在庫・価格の情報は 2026-10-14〜22 時点。買いに行く前にもう一度確かめる。

## 構成のあらまし

| 項目 | 内容 |
|---|---|
| 音の出し方 | Pico で波形を計算し、62.5 kHz の PWM で H ブリッジを動かす（1 台 1 声）。予備として音の高さの矩形波も出せる |
| 回路 | Raspberry Pi Pico ＋ Pololu DRV8874 基板（#4035）× 4、12 V。ユニバーサル基板（秋月 104708）に手はんだ。温度センサーなどは載せず、空きピンだけ残す |
| 取り付け | HDD を 1 台ずつ木の板に固定して響かせる。足りなければ圧電ピックアップ＋PA で拡声 |
| 安全 | 通信の途絶・プログラムの停止（Pico 内蔵のウォッチドッグ）から 0.5 秒以内に全停止。倒したままにできる停止スイッチ |
| 費用の目安 | 約 ¥3.5 万（HDD・基板の発注込み）。ピックアップと工具も買うと約 ¥4.4 万 |

## 次にやること

1. ユニバーサル基板の配置と配線を仕上げる（`ユニバーサル基板/README.md` の「再開のしかた」）。ジャンパーの数と詰め具合のどちらを優先するか、ユーザーに聞く。
2. 組み立ての手順書・配線表・導通チェックの表を作る。`部品表.md` と仕様書（v0.8 ユニバーサル基板版）に部品の差し替えを入れる。
3. HDD と部品を秋葉原で買う。MBR3045FCT と変換基板・ピンソケットは、穴に入るか試し挿しする。Pololu 基板を改造し、1 枚ずつ確かめる（仕様書 8.1）。
4. ジャンパー線で HDD 1 台を鳴らして試験する（仕様書 8.1）: 音の出し方、発熱の目安、アームの片寄り、拡声が要るか。
5. ユニバーサル基板を組み立て、段階的に確かめ、本番の HDD 1 台ずつ温度の試験をする（仕様書 8.2）。
6. ファームウェアを書く（仕様書 7 章）。
7. 4 台そろえて 1 曲通す。当日は仕様書 8.4 のとおり。

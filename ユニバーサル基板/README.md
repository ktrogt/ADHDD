## 部品の差し替え（ユニバーサル基板に載せるため。Claude 承認済み。部品表と仕様書にはまだ入れていない）

| 部品 | 元 | ユニバーサル基板版 | 理由 |
|---|---|---|---|
| コイルのコネクタ × 4 | VH 2 ピン | ✓ XH 3 ピンの両端（B3B-XH-A・XHP-3・圧着済みの線 131312、真ん中は空き） | VH は 3.96 mm ピッチで格子に合わない。受信用は XH 2 ピンなので挿し間違えない |
| DC ジャック | MJ-179PH | ✓ 秋月 105148（2.1 mm 標準 DC ジャック DIP 化キット、20 V 3 A） | 板状の端子は穴に入らない。パネル取付の 22234 と 10 A のキットはフォーク型のプラグ専用なので避けた |
| D103（逆接続保護） | 1N5822 | ✓ MBR3045FCT（秋月 114030、片側だけ使う） | 1N5822 の足（1.2〜1.3 mm）は 1.0 mm の穴に入らない。**MBR3045FCT も穴との余裕が計算上 0.03 mm なので、買ったら試し挿し**。入らなければ 1N5822 に戻して 2 穴を 1.5 mm に広げる |
| 受信バッファ | 74AHC1G125（表面実装） | 同じ IC を変換基板（秋月 115520）に載せ、DIP6 として挿す | 格子に載らない。IC をはんだ付けする前に変換基板の導通を確かめる |
| Pico・Pololu | — | ピンソケット（分割ロングピンソケット）で抜き差しできるように | — |
| テストポイント | 基板のパッド | ピンヘッダの 1 ピン | — |

Pololu #4035 の 2 番と 13 番の GND は、Pololu の回路図ではドライバの基板の中で同じ GND（L5 の Astra が確認、出典 https://www.pololu.com/file/0J1862/drv887x-single-brushed-dc-motor-driver-carrier-schematic.pdf 。Claude は未確認）。L5 ではこれを使って 2 番の配線を省いている。

   ```

   ```

3. 最後に Claude が日本語の組み立て手順書・配線表・導通チェックの表を書き、部品表と仕様書（v0.8 ユニバーサル基板版）を直す。
